# pairwise-video-rotation-meta

手机竖拍的视频在电脑上播放变成横的，容器里的 display matrix 没被读取，解码器按存储方向输出；旋转元数据是 90 度但宽高没交换，缩略图被拉成细长条；滤镜链在旋转之前做裁剪，裁剪坐标按旋转后的画面算，边缘切歪；转码时 autorotate 与手动旋转同时开，画面转了 180 度；HDR 视频旋转后元数据丢失，播放器回退到 SDR；慢动作素材的旋转矩阵与时间缩放元数据冲突，导出后方向对但速度不对；缩略图提取器只读 EXIF 不读容器 matrix，手机视频缩略图方向错；旋转 90 度后样本宽高比没重算，像素变成非方形；多次转码每次写入新的 rotation 而不清除旧的，累计旋转 270 度；旋转后的叠加字幕坐标系没跟着变换，字幕跑到画面外。media/video_rotation_meta.py 是核心，tests/test_video_rotation_meta.py 15个红。要修的是：读 display matrix；旋转交换宽高；裁剪在旋转后；避免双重旋转；保留 HDR 元数据；处理时间缩放；缩略图读容器；重算宽高比；清除旧矩阵；字幕坐标随旋转。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
